# 🚗 AutoMart - Second-Hand Car Marketplace

AutoMart is a Full-Stack Java Web Application that allows users to buy and explore second-hand vehicles online. The platform provides a user-friendly interface for browsing cars, searching with filters, saving favorite vehicles, and contacting dealers. It also includes an Admin Dashboard for managing vehicle listings and users.

## 📌 Features

### 👤 User Module

* User Registration & Login
* Browse Available Vehicles
* View Detailed Car Information
* Search Cars by Keywords
* Filter Cars by Brand, Price, Fuel Type, and Model
* Add/Remove Cars from Wishlist
* Contact Dealer/Seller
* User Profile Management

### 👨‍💼 Admin Module

* Secure Admin Login
* Add New Vehicle Listings
* Update Vehicle Information
* Delete Vehicle Listings
* Manage Users
* View Dashboard Statistics
* Monitor Vehicle Inventory

## ⚙️ Installation & Setup

### Prerequisites

* Java JDK 8+
* Eclipse IDE
* Apache Tomcat 9+
* MySQL Server

### Steps

1. Clone the repository

```bash
git clone https://github.com/swapnilbharate/AutoMart.git
```

2. Import project into Eclipse.

3. Create MySQL database:

```sql
CREATE DATABASE automart;
```

4. Import the SQL file.

5. Configure database credentials in JDBC Connection class.

6. Add MySQL JDBC Driver.

7. Configure Apache Tomcat Server.

8. Run the project.
